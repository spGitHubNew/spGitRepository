# CounterSign — AtliQ Contract Risk Analyzer

A pre-signature contract-review copilot plus a Promise Register for AtliQ.

- [`countersign/`](countersign/) — the app (Python 3.10+, standard library only). See its [README](countersign/README.md).
- [`Dataset/`](Dataset/) — the AtliQ contracts, notes and entity data the app reads.
- [`test_contracts/`](test_contracts/) — synthetic contracts for end-to-end testing.

## Run

```bash
cd countersign
python app.py
```

Then open http://localhost:8765.
